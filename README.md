# [NutriCalc](https://matheuscoletti08.github.io/Calory/)

Calculadora nutricional desenvolvida com **HTML, CSS e JavaScript**, criada para estimar necessidades calóricas e distribuição de macronutrientes a partir dos dados informados pelo usuário.

## Sobre o projeto

O NutriCalc permite informar dados como idade, sexo, peso, altura, nível de atividade física e objetivo.

A partir dessas informações, o sistema calcula:

* **IMC**
* **Classificação do IMC**
* **TMB** — Taxa Metabólica Basal
* **Estimativa de calorias diárias**
* Quantidade de **Proteínas**
* Quantidade de **Carboidratos**
* Quantidade de **Gorduras**

O projeto foi desenvolvido com foco em **lógica de programação, manipulação do DOM e construção de interfaces web responsivas**, sem utilização de frameworks.
